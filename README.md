# Ugliest-Website-
A Contest for Cycle 60 for who can make the ugliest website. Is this site ugly enough?
# tech stack 
Html, CSS, and a little java script
work safe
Individual project
The Challenge
Build the ugliest website you can — and make it survive. You have one session to ship a single page so visually offensive it makes people flinch, with one twist that changes everything: it has to actually work.
Anyone can throw garbage on a screen. The real flex is building something hideous that still loads, works on a phone, and lets a visitor do what the page promises. Lean all the way into bad taste — but every ugly choice has to be one you made on purpose and can defend.
Why we're doing this: "make it good" makes people freeze, so "make it terrible" is the unlock. You'll pick up more real HTML and CSS in one session than a week of tutorials, because breaking the rules this creatively means you have to know them cold.
The One Rule: It Has to Actually Work
Ugly is the easy part; functional is the bar. Your monstrosity has to pass a basic working-website check, or it's out — no matter how gloriously it hurts to look at. A real visitor should be able to land on your page and get something done, even while their eyes are screaming.
To count as "working," your site must:
Load clean — no blank page, no broken console, no missing files or images.
Work on phone and laptop — usable (not pretty) at both mobile and desktop widths.
Let a visitor do at least one thing — a working link, a form that submits, a menu that opens, a play/pause that plays. The page performs its promise.
Keep navigation functional — every button and link goes where it says. No dead ends.
Stay legible — eye-searing colors are encouraged, but a visitor still has to be able to read the actual content. Invisible text is cheating.
Be your own work, built today — hand-written HTML/CSS, a little JavaScript if you want. No dumping a template and recoloring it.
If a judge can't use it, it can't score. The ugliness is the costume; the working site underneath is the whole point.
Ground Rules
Read these before you start so nothing gets you knocked out on a technicality.
Time: about 60 minutes to build. Kickoff wraps at 12:00; everything's due at 1:00 sharp. Keep a clock visible
Solo: Everyone builds their own site. Trade cursed ideas all you want, but the code is yours.
From scratch, today: Start from a blank file at kickoff. No pre-built sites, no templates you recolor, no generating the whole page for you. Hand-roll it.
One page: A single page is all you need. Go deep on one glorious disaster rather than wide across five.
Tools: Plain HTML and CSS are the core; a little JavaScript is fair game. Use your normal editor and a browser (or CodePen if you'd rather share a quick link). Looking things up in the docs is encouraged.
Keep it work-safe: This gets shown to the whole room. Nothing NSFW, nothing aimed at a real person, nothing you wouldn't put in front of a client. Offend the eyes, not people.
Submit before the buzzer: Have your page saved and your link ready to drop (or be set to screen-share) the moment time's up. Late means not judged.
Idea Bank: Ways to Assault the Senses
Stuck on how to be ugly? You're overthinking it. Steal freely from the menu below, combine recklessly, and aim for intentional crimes against design — not random noise.
Color & type
Clashing neon on neon — lime text on a hot-pink background, anyone?
Comic Sans. Or five different fonts in one sentence.
Text in a dozen sizes and three directions.
A tiny tiled background image sitting right behind your body text.
Motion & chaos
A scrolling marquee banner (recreate the old <marquee> in CSS if you want style points).
Everything blinks, spins, or pulses on a loop.
A custom cursor — ideally one that leaves a trail.
Something auto-plays on load (keep it muted — see the rules).
Peak 1999 energy
A "You are visitor #000001" hit counter.
Under-construction GIFs and animated flame dividers.
A guestbook nobody asked for.
Badges: "Best viewed in Netscape," "Made with Notepad."
Cursed layout (that still works!)
A button that dodges your mouse but still clicks.
A nav bar where every link is a different mismatched style.
A pop-up you have to close to keep going (the working kind).
Content you have to scroll sideways to reach.
Pick a theme and commit. A page that's confidently one terrible idea beats a pile of random ugly every time.
How You Win
Winners get picked at the reveal across a few categories, so there's more than one way to take home glory. Two things decide everything:
How ugly is it, really? Does it make the room groan, laugh, or physically recoil? Bonus for one committed theme over random mess.
Does it actually work? If we can't use it, it can't win. Hideous and flawless beats hideous and broken every time.
